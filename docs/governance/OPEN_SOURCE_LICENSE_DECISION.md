# Open-source licensing decision

## Status: owner decision required

The repository is public, but no license has been selected in this change. Public visibility alone does not grant permission to reuse, modify, distribute or sublicense the source code.

Before inviting external contributions or advertising the project as open source, the repository owner must choose and approve a license after considering:
- whether commercial use and redistribution should be permitted;
- whether derivative works must disclose source;
- patent and trademark considerations;
- compatibility with third-party dependencies;
- contributor licensing and intellectual-property expectations.

Do not add a license file or describe the project as open source until the owner has made this decision. The selected license must be added as the root `LICENSE` file and referenced in the README and contribution policy.

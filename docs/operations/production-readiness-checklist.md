# Production readiness checklist

- [ ] Authentication, authorization and tenant isolation independently tested
- [ ] Secrets externalized and rotated
- [ ] TLS and encryption at rest enabled
- [ ] Transaction/outbox atomicity tested under failure
- [ ] Idempotency and replay tested
- [ ] Financial reconciliation controls independently verified
- [ ] Event schema compatibility enforced
- [ ] DLQ inspection and replay runbooks tested
- [ ] SLOs and actionable alerts configured
- [ ] Load, soak, stress and chaos tests completed
- [ ] Backup restore and disaster recovery exercised
- [ ] Data retention and privacy requirements approved
- [ ] Security review and dependency scanning passed
- [ ] Capacity and cost model approved
- [ ] Rollback and incident procedures rehearsed
